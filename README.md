# PocketLedger site

Static pages for GitHub Pages: home, Privacy Policy and Terms & Conditions. No build step.

- Files: `index.html`, `privacy.html`, `terms.html`, `404.html`, `style.css`, `assets/`.
- Live address: https://pocketledger.mehedisiam.com/ (custom domain; `CNAME` file in this repo, Cloudflare DNS record `pocketledger` CNAME to `mehedihsiam.github.io`, DNS only, HTTPS enforced in Settings > Pages).
- Keep `privacy.html` in step with the app (`docs/privacy-policy.md` in the app repository) and update the "Last updated" date when it changes.
